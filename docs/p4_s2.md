## Verdict

**No keyless Sentinel-2 pixel bulk — the dim stays NULL with an Estonian reason.**
Catalogue metadata is openly readable (STAC collection + today's Tallinn
scene record), but every pixel asset is an `s3://eodata/...` href behind
the Copernicus Data Space S3, whose docs require a registered account and
per-account S3 credentials. A per-listing NDVI year-delta needs two keyed
vintage pulls plus raster math (red/NIR bands B04/B08, cloud masking,
differencing) — none of which this demo will do without an account (per
#305: no account creation, no credential use). There is no ingestion to
cache, no TTL to state beyond this one-off check, and no honest coarse
change flag to paint from metadata alone.
